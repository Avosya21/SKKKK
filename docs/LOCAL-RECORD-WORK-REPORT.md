# Локальная запись созвона — отчёт о проделанной работе

Дата: **2026-11-19**. Портал: `https://127.0.0.1:777`, песочница проектов.

Итог: запись сотрудника больше не зависит от того, успел ли он второй раз нажать «Запись». Пока страница жива, файл сохраняется как MP4 с перемоткой. Если вкладка умерла, при следующем открытии портала скачивается WebM. На время сохранения на экране просят не закрывать страницу.

## 1. С чего начали

Кнопка «Запись» в комнате сотрудника уже сохраняла MP4 при повторном нажатии. Дальше всплыли дыры, из‑за которых небрежный выход терял файл или снова отдавал WebM без перемотки:

- «Выйти» и «Завершить для всех» уходили со страницы раньше, чем браузер принимал скачивание;
- в углу комнаты висели лишние строки про связь, дорожки и «Вы в комнате»;
- плашка браузера «Закрыть окно» при показе экрана гасила сам показ, а кнопка на пульте оставалась включённой;
- куски записи жили только в памяти вкладки: обновление, закрытие и падение страницы стирали их;
- закрытие комнаты сервером, удаление участника и вторая вкладка не останавливали запись.

## 2. Что сделано

| Ситуация | Что получает человек |
|---|---|
| Второй раз нажал «Запись» | MP4 с перемоткой в «Загрузки» |
| «Выйти», не останавливая запись | Сначала MP4, потом выход |
| Создатель нажал «Завершить для всех» | Его MP4 сохраняется до закрытия комнаты. У остальных с записью — свой MP4 и автоматический уход, даже если сигнал «комната закрыта» пришёл раньше опроса |
| Человека удалили из комнаты | MP4, затем уход |
| Открыл ту же комнату второй раз | MP4, на экране остаётся «Вы вошли с другой вкладки» |
| Связь пропала надолго | MP4 сразу, ещё до попытки вернуться |
| «Назад», ссылка в шапке, «Выйти» из портала | Сначала MP4, потом переход |
| Обновил страницу, закрыл вкладку, браузер упал | WebM без перемотки при следующем открытии любой страницы портала. Плашка «Скачать WebM» / «Не сохранять» |
| Короткий обрыв связи | Запись не обрывается, связь возвращается сама |
| Записи не было, комнату закрыли | Текст «Комната закрыта», без попытки войти заново |

Пока файл собирается, комнату закрывает надпись: «Погодите, не закрывайте страницу. Идёт сохранение записи.» Закрыть вкладку в этот момент молча нельзя: браузер переспрашивает. Эта фраза добавлена в список «Исправлено» от 2026-11-19.

Угол комнаты больше не показывает связь, «Мои дорожки» и «Слышу людей». Остаются «Вы ведёте локальную запись», список тех, кто пишет локально, и строка «В комнате (N)».

Плашка браузера «Закрыть окно» при демонстрации экрана выключает и кнопку на пульте. Перезаход и обрыв связи намерение «показывать экран» не сбрасывают.

Запасная копия пишется в браузер каждую секунду (IndexedDB, база `primaryanalitics-local-record`). В проект и на сервер файл не кладётся. Успешный MP4 эту копию стирает, чтобы она не скачалась второй раз. Если процесс браузера убит, в WebM попадают только секунды, которые уже успели записаться.

## 3. Чем проверено

Живой прогон `scripts/e2e/e2e_meeting_record.py` на Chromium, стенд `:777`:

- кнопка записи, «Выйти» и «Завершить для всех» сохраняют MP4 (H.264 и AAC, перемотка есть);
- при «Выйти» видна плашка «не закрывайте», затем скачивается MP4 и страница уходит из комнаты;
- обновление страницы во время записи скачивает WebM;
- закрытие комнаты, вторая вкладка и «Назад» во время записи сохраняют MP4;
- Firefox локальную запись по-прежнему не предлагает.

Отдельно `scripts/e2e/e2e_meeting_stability.py --only s3`: короткий обрыв запись не режет, закрытая комната без записи показывает «Комната закрыта» и не уходит в перезаход. Сценарий устойчивости s1: после перезахода экран восстанавливается, а остановка показа в браузере гасит кнопку.

Контракт скриптов без браузера: `app/app/tests/test_meeting_local_record.py`.

## 4. Что сознательно не обещано

Обновление и закрытие вкладки не могут дождаться перекодирования в MP4: страница уже умирает. Поэтому там WebM. Убитый процесс браузера не дописывает последнюю незафиксированную секунду.

Локальная запись есть только у сотрудника в комнате портала. Гость её не ведёт.

## 5. Где это лежит

- `app/app/static/meeting_local_record.js` — захват, remux, запасная копия в браузере, восстановление WebM
- `app/app/static/meeting_room.js` — выход, закрытие комнаты, вторая вкладка, «Назад», плашка «не закрывайте»
- `app/app/templates/base.html` — скрипт записи подключён на всех страницах портала, чтобы WebM нашёлся и вне комнаты
- `app/app/changelog.json` — строка «Исправлено» от 2026-11-19
- `scripts/e2e/e2e_meeting_record.py` — проверка перечисленных сценариев
- `docs/PROJECT-MAP.md` — описание кнопок и этих выходов
