# Этап 6. Граф, заметки, конфликты

## Цель

Знания перестают быть плоским списком: артефакты, сущности и заметки становятся связанным графом, люди добавляют экспертные связи, противоречия попадают в очередь администратора.

## Предусловия

Этап 5 зелёный.

## Шаги

1. **Посев графа** (модуль 6) — на данных этапа 5, без Neo4j:
   - узлы: артефакт, сущности, системная заметка с кратким изложением;
   - рёбра `CONTAINS`, `MENTIONS`, `SUMMARIZES`;
   - поиск похожих сущностей среди **предыдущих** артефактов проекта; выше порога — `SEMANTICALLY_RELATED` с оценкой;
   - тот же тип сущности при расходящихся значениях — `POTENTIAL_CONFLICT`;
   - статус `graph_seeded`.

2. **Ручные заметки** (модуль 7): текст, файл в `project_notes/`, узел `UserNote`, рёбра `REFERENCES` на выбранные узлы.

3. **Ручные связи**: два узла, тип из списка (`REFINES`, `CONTRADICTS`, `SUPPORTS`, `DEPENDS_ON`, `CLARIFIES`, `EXAMPLES`, свой), обязательный комментарий «почему». `is_automatic = false`, `created_by`.

4. **Права**: свои заметки и связи правит автор, любые — администратор. Автоматические рёбра может удалить только администратор.

5. **Конфликты** (модуль 8):
   - автоматическое разрешение **только** при явной формулировке отмены в более позднем артефакте («отменяем», «вместо пункта», «исправляем»);
   - во всех прочих случаях — `pending_manual` и уведомление администратора;
   - решение фиксируется в `resolutions`, проигравшая сущность `is_active = false`, появляется ребро `RESOLVES`;
   - страница `/admin/conflicts`: оба варианта, источники, даты, веса, кнопка выбора и поле причины.

6. **Визуализация** (модуль 10): страница графа, цвет по типу узла, размер по числу связей, подписи рёбер, фильтры по типу, времени, автору, поиск с подсветкой. Ограничение глубины и числа узлов, чтобы страница не легла на большом проекте.

## Что появляется на диске

```
data\projects\{id}\project_notes\user_note_2026-08-20_ivan.txt
```

Граф живёт в таблицах `entities`, `links`, `user_notes`, `note_refs`.

## Проверки

Сценарий: загрузить PDF заказчика с бюджетом 3 млн, затем стенограмму созвона, где звучит 4 млн.

Открыть `http://127.0.0.1:1111/projects/{id}/graph` и `.../conflicts`, сделать два скриншота: граф с явно видной парой `POTENTIAL_CONFLICT` (обычно другим цветом ребра) и очередь конфликтов администратора с обоими вариантами значения и весами источников — сверить с описанием шага 5/6 и с тем, что на графе физически видно ребро конфликта, а не только запись в БД.

| Проверка | Действие | Ожидание |
|---|---|---|
| Посев | Обработать артефакт | Узлы и рёбра появились, статус `graph_seeded` |
| Кросс-связи | Второй артефакт на ту же тему | `SEMANTICALLY_RELATED` между сущностями разных артефактов |
| Конфликт | Сценарий с бюджетом | Появился `POTENTIAL_CONFLICT`, ТЗ **не** изменилось само |
| Ручное разрешение | Админ выбирает победителя | Запись в `resolutions`, проигравшая неактивна, ребро `RESOLVES` |
| Явная отмена | Артефакт с фразой «отменяем прежнее решение по бюджету» | Разрешилось автоматически, причина зафиксирована |
| Заметка | Создать заметку с привязкой к двум узлам | Файл на диске, два ребра `REFERENCES` |
| Ручная связь | Связать сущности как `DEPENDS_ON` | Ребро с комментарием, `is_automatic = false` |
| Права | `user` правит чужую заметку | 403 |
| Права админа | Админ удаляет автоматическое ребро | Успех |
| Граф в UI | Открыть страницу графа | Узлы видны, фильтры и поиск работают |
| Большой граф | Проект с сотнями сущностей | Страница открывается, применяется ограничение узлов |

## Критерий готовности

- [ ] Граф засевается автоматически, кросс-связи между артефактами появляются
- [ ] Противоречие по умолчанию уходит человеку, а не решается тихо
- [ ] Автоматическое разрешение срабатывает только на явной отмене
- [ ] Заметки и ручные связи создаются, права соблюдаются
- [ ] Страница графа открывается на большом проекте
- [ ] Тесты `test_graph.py`, `test_notes.py`, `test_conflicts.py` зелёные

## Типичные отказы

| Симптом | Причина | Что делать |
|---|---|---|
| Связей слишком много, граф нечитаем | Порог занижен | Калибровка порога из этапа 5 |
| Связей нет вовсе | Порог завышен или эмбеддинги не по тем текстам | Проверить, что сравниваются значения сущностей |
| Всё уходит в конфликты | Разные формулировки одного решения | Учитывать тип сущности и близость значений, а не только совпадение типа |
| Страница графа тормозит | Много узлов | Ограничение по глубине и числу, догрузка по клику |
