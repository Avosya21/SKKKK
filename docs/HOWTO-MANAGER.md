# How-to: Primary Analytics (для менеджера)

Портал: адрес и **пароль роли `manager`** даёт тот, кто поднял систему.  
В шапке сайта написано **Primary Analytics**.

---

## 1. Войти

Откройте портал → форма **Вход**.

| Поле | Что писать |
|------|------------|
| Имя (логин) | Как в списке допущенных (почта или имя). Регистр не важен |
| Telegram ID | Просто сохраняется. Можно любой, на вход не влияет |
| Пароль роли | Пароль `manager` |

**Войти.** Откроется список **ваших** проектов: те, что создали вы, куда загружали файлы, где писали в чат, или куда вас добавили в блоке **Выдать доступ**. Другой пароль роли меняет права кнопок, но эти проекты никуда не денутся. Чужие, к которым вы не прикасались, не видны. В шапке справа — ваше имя и иконка выхода. Сессия в этом браузере держится **30 дней**, пока сами не выйдете.

Первый вход с этим **логином** создаёт учётку, если имя есть в списке допущенных. Дальше входите тем же логином — чат и история остаются, даже если Telegram ID другой. Роль каждый раз берётся из пароля: менеджерский пароль — менеджер, админский — админ.

---

## 2. Создать проект

**Новый проект** → название (обязательно) + описание (по желанию) → **Создать**.  
Клик по названию — внутрь проекта.

---

## 3. Загрузить материалы

Блок **Добавить материалы**.

1. **Тип:** `Созвон` / `Документ` / `Заметка` / `Скриншот`.
2. Выбрать файл(ы).
3. **Загрузить.**

Файл появляется в таблице **Артефакты проекта**. Статус сам обновляется каждые несколько секунд.

Созвон: `В очереди` → `Подготовка` → `ASR` → … → **`Спикеры`**. Это не «готово» — дальше шаг 4.  
Документ / заметка / скриншот: доходит до **`Готово`** без спикеров.

Созвон на час может идти **десятки минут**. Очередь одна: пока крутится один файл, следующий ждёт.

---

## 4. Подписать, кто говорил (только созвон)

Когда расшифровка закончилась и появились дорожки голосов, жёлтая кнопка **match**. Пока идёт ASR, её нет: сопоставлять ещё нечего.

1. Откроется страница голосов. У каждого ID — клип **▶**.
2. На карточке в поле **Кто это** выберите человека из списка: сверху — похожие голоса из базы с процентом сходства, ниже — люди проекта и сотрудники. Нет в списке — впишите имя и выберите **+ Новый человек**. Затем **Компания** (выбрать из списка или вписать новую), **Сторона** (исполнитель / заказчик), при желании **Должность** → **Подтвердить**. Имя попадёт в стенограмму, а человек — в «Люди и стороны» проекта: второй раз на странице проекта его заполнять не нужно. Если система узнала человека, поля уже заполнены — проверьте их и всё равно нажмите **Подтвердить**: без этого созвон не считается подписанным. Без компании и стороны кнопка неактивна. Ошиблись человеком — выберите другого: голос перепривяжется, у прежнего ничего не изменится. Опечатка в имени — ссылка **Исправить написание имени** (имя поменяется во всех созвонах этого голоса).
3. Два ID — один человек → **Объединить**.
4. Справа в **Базе голосов** могут быть уже знакомые люди — можно привязать к ним, а не заводить заново.
5. **Пересчитать подсказки** — не обязательно.

Когда **все** спикеры названы, на странице проекта появится **Подтвердить спикеров**. Раньше её нет — сначала match.

Статус: `Спикеры ✓` → … → **`Готово`**. Появится зелёный тост «файл обработан».  
Без **Подтвердить спикеров** выжимка созвона и чат по этому файлу не соберутся.

---

## 5. Стенограмма и выжимка созвона

В таблице клик по **имени файла** (когда не ошибка).

- Плеер + текст. Клик по времени — перемотка.
- Вкладки сверху: **Итоговое резюме созвона** (протокол, кто/что/срок) и **Краткое резюме**.
- Скачать: **Выжимка Word**, **Краткое резюме созвона**, **Стенограмма .txt**.

Имена кривые после подписи — **Пересобрать выжимку** на этой же странице (минуты). Не путать с **Пересобрать** на странице проекта.

---

## 5.1. Документ

Клик по имени файла документа / заметки / скриншота открывает **резюме документа**, не сырой текст.

- Сверху протокол (суть, положения, обязательства, открытые вопросы).
- Полный текст — свёрнутый блок внизу.
- **Пересобрать выжимку**, **Выжимка Word**, **Полный текст**.

Индекс и чат по-прежнему используют полный текст. Пересборка выжимки его не затирает.

---

## 6. Выжимка проекта и чат

На странице проекта, ниже таблицы:

- Слева **Итоговая выжимка по проекту** — сводка по всем готовым файлам. Сама подтягивается после обработки. Кнопка **Пересобрать** у менеджера **не работает** (только admin).
- Справа **Чат с ИИ по проекту** — вопрос → **Спросить**. Лента общения этого логина в проекте сохраняется и показывается при открытии. ИИ читает **ту же ленту** целиком, чтобы понимать «а это?», плюс чанки, ближайшие решения/задачи/факты и выжимку проекта, если она уже собрана. Внизу ответа — источники. Пока нет материалов и выжимки, чат скажет «не найдено».

---

## 7. Задачи

Блок **Задачи** (по умолчанию свёрнут) → клик по заголовку.

Все задачи проекта: те, что система вытащила из созвонов и документов, и добавленные вручную. Вкладки: **Открытые**, **Просрочено**, **На неделе**, **Без срока**, **ТЗ и план**, **Сделано**, **Все**; на «ТЗ и план» — положения ТЗ и этапы графика из документов: это не поручения, они не считаются просроченными; справа — фильтр по ответственному. Виды: **Список** / **Календарь** (в календаре — задачи с датой срока).

Менеджер и администратор правят прямо в строке:
- **статус** — открыта, в работе, сделано, отменена;
- **ответственный** — имя (подсказки — из уже названных);
- **срок** — дата.

Изменённая задача помечается «изменено вручную: кто, когда», при наведении видно, что было. Правки сохраняются и после **Обновить из материалов** или переизвлечения требований.

**+ Задача** — добавить свою задачу (описание, ответственный, срок). Свою задачу можно **убрать**.

## 7.1. Что нового

Наверху страницы проекта — полоска **Что нового с …**: что обработано с прошлого захода и что из этого извлечено, какие решения сменились, просроченные задачи. Клик по строке открывает нужный блок. **Скрыть** — до следующего обработанного материала. При первом заходе в проект полоски нет.

---

## 8. Выдать доступ

Блок **Выдать доступ** (под MCP, по умолчанию свёрнут). В списке все, кто есть в файле допущенных (`Login_up.txt`), даже если человек ещё ни разу не входил. Выберите человека и роль: **Менеджер** или **Участник**. Админом через этот список сделать нельзя.

Кого добавите — увидит проект в своём списке. Менеджер (если вошёл паролем менеджера) может match и выжимки; участник и любой вход паролем **user** — только смотреть и чат, без match / MCP / «Выдать доступ».

---

## 9. Удаление (отменить нельзя)

- Один файл: корзина в строке → галочка → **Удалить**. Проект остаётся.
- Весь проект: на списке проектов стрелка справа от названия → **Удалить проект** → галочка → **Удалить**. Стирается всё.

---

## Не нажимать

| Кнопка | Зачем она |
|--------|-----------|
| **лаб** | Кнопки нет: лаборатория только у admin |
| **Пересобрать** (выжимка проекта) | Только admin |
| **Создать ключ** в MCP | Для Cursor/интеграций, не для просмотра |

Если статус **Ошибка** — напишите тому, кто ведёт стенд. Не перезаливайте тот же файл пачкой: очередь одна.
