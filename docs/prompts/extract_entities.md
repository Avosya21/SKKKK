# Промпт: извлечение сущностей

```
Извлеки из текста структурированную информацию. Ответь ТОЛЬКО валидным JSON без markdown-ограждений.
Если поле неизвестно — null или пустой массив. Не выдумывай факты, которых нет в тексте.

## Задачи и сроки (важно)

- Каждое обещание, поручение, action item — отдельный объект в массиве tasks.
- **Одно обязательство — одна task:** если несколько фраз описывают *состав одного результата*
  (например, «подготовить КП» и «включить в КП кейсы», «без демо-стенда») — это **одна** task
  с полным описанием, а не несколько tasks с одним deadline.
- Условия и критерии готовности (что включить, чего не делать, формат) пиши в description той же task,
  не создавай отдельную task только ради «включить X в Y».
- Отдельная task — только если это самостоятельное действие со своим исполнителем и/или другим сроком.
- Если в речи назван срок, дата, дедлайн, «до конца недели», «к пятнице», «четверг–пятница», «к 15.03» —
  обязательно запиши его в tasks[].deadline дословно или кратко на русском.
- Не клади сроки только в decisions: если есть и действие, и срок — это task с заполненным deadline.
- decisions — только утверждённые решения без отдельного исполнителя/срока («решили использовать ИНН», «мастер-система — Bitrix»).
- assignee — имя человека, команды или роли из текста (Acme, Алина, Елена, бухгалтерия).
  Не используй SPEAKER_00/01, если в тексте или контексте есть реальное имя.
- Если в запросе передан reference_date (дата созвона/материала) и срок относительный
  («четверг–пятница», «до конца недели», «на следующей неделе») — в deadline пиши также
  ISO-дату (20XX-MM-DD) или диапазон «20XX-MM-DD — 20XX-MM-DD», посчитанный от reference_date.
- status: open | done | cancelled | unknown — только если явно следует из текста, иначе unknown.
- Если срок не назван — deadline: null (не пиши «срок не указан» в поле deadline).

## Формат

{
  "artifact_id": "<подставить>",
  "source_type": "call|document|note|screenshot",
  "timestamp": "<ISO8601 или null>",
  "summary": "3-5 предложений",
  "decisions": ["..."],
  "tasks": [{"description": "", "assignee": null, "deadline": null, "status": "unknown"}],
  "facts": {},
  "mentions": [{"name": "", "relation": "mentions|refines|contradicts|supports"}],
  "participants": [{"name": "", "role": null}]
}
```
