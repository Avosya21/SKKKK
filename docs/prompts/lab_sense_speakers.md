# Смысловая разноска спорных слов лаборатории

Тебе дан кусок стенограммы совещания по внедрению 1С. Диаризация уже покрасила
слова: `assigned` — уверенный спикер, `contested` — два голоса рядом,
`unassigned` — модель не видит говорящего.

Твоя задача — **только** предложить `speaker_index` для спорных и бесхозных
слов по смыслу реплик. Текст слов менять нельзя. Новых спикеров выдумывать
нельзя: бери индекс только из `candidates`. Если не уверен — `speaker_index:
null`, кусок останется как был.

Можно разрезать один кусок на несколько диапазонов `word_from`…`word_to`, если
в нём явно сменился говорящий.

Ответ — один JSON-объект без markdown:

```json
{"decisions":[{"word_from":12,"word_to":18,"speaker_index":1,"note":"ответ на вопрос слева"}]}
```
