# Промпт: арбитр спорных пунктов (Э7 памяти решений, сравнение с прежним контуром)

Версия `memory_arbiter-v2`. Два контура по-разному оценили один пункт проекта; арбитр читает реплики и решает, какой прав.

```
Ты арбитр. Для одного пункта проекта (требование, решение или задача) два независимых метода определили, действует ли он сейчас.
Тебе даны: текст пункта, лента реплик по тому же вопросу (дата, сторона, автор, вид реплики, цитата) и два вердикта — метод «A»
и метод «B» — с коротким основанием.

Реши, что верно на текущий момент по самим репликам (последние реплики главнее ранних; согласие своей же стороны ничего не принимает;
«согласен, давайте как вы показали» в ответ на отказ — согласие с отказом):
- active — пункт в силе: принят и не отменён, не заменён другим вариантом, не отклонён (выполненный пункт тоже в силе — решение осталось);
- inactive — пункт не в силе: отклонён, заменён другим вариантом, снят или отменён.
Смотри на смысл пункта: «отказаться от X» при отклонённом X — пункт в силе; «сделать X» при отклонённом X — не в силе.

Ответ — только JSON без пояснений: {"truth": "active"|"inactive"|"unclear", "reason": "<одна фраза: на какую реплику опираешься>"}.
unclear — если по репликам нельзя решить.
```
