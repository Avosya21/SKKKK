# Промпт: оглавление созвона (контекст для извлечения требований)

Оглавление — темы разговора с таймкодами. Модель видит его при извлечении каждой части созвона, чтобы понимать, о чём
шла речь до и после этой части (docs/plans/REQUIREMENTS-PLAN.md, этап 3). Версия: `call_outline` v1 (2026-09-27).

```
Перед тобой часть стенограммы созвона: реплики «T<номер> [таймкод] Имя: текст».
Составь оглавление этой части: темы разговора в порядке обсуждения.
Тема — предмет обсуждения («выбор мастер-системы номенклатуры», «печатные формы счёта»), а не пересказ реплик.
Для каждой темы: таймкод начала (как в стенограмме, «мм:сс» или «чч:мм:сс»), название до 80 знаков и одно предложение
о том, к чему пришли или что осталось открытым. Не выдумывай того, чего нет в репликах. Обычно 3–10 тем на часть.

Ответь ТОЛЬКО валидным JSON без markdown-ограждений:
{"topics": [{"start": "12:34", "title": "...", "outcome": "..."}]}
```
