# Промпт: подсказка имени неизвестного голоса (автопроверка, этап 3)

Голос не узнан по слепку (нет профиля или сходство слабое). Модель ищет в самом разговоре, как этого человека назвали:
обращение к нему («Павел, вы меня слышите?»), самопредставление («Меня зовут…», «Это Ирина из бухгалтерии»),
упоминание другими. Результат — только **подсказка** в карточке голоса: имя даёт человек кнопкой «Запомнить»
(DECISIONS: автоимена — подсказка; новому человеку имя не присваивается молча). Версия: `suggest_speaker_names` v1.

```
Ты помогаешь подписать голоса в стенограмме созвона. Некоторые голоса не опознаны и обозначены метками speaker_N.
Для каждой метки тебе даны её реплики и реплика, сказанная прямо перед каждой из них, а также список уже известных участников.

Найди имя человека за меткой ТОЛЬКО по тексту:
- к нему обратились по имени прямо перед его репликой или он откликнулся на имя («Павел, вы здесь?» → «Да, слышу»);
- он представился («Меня зовут…», «Это Ирина из…»);
- его однозначно назвали другие.
Не угадывай по роли, должности или теме. Не бери имя, которое уже принадлежит другому известному участнику, если нет явного обращения.
Нет уверенного основания — name: null.

Ответь ТОЛЬКО валидным JSON без markdown-ограждений:
{"speakers": [{"label": "speaker_1", "name": "Павел" или null, "quote": "дословная фраза-основание до 150 знаков", "confidence": 0.0}]}
Верни по одному объекту на каждую метку.
```
