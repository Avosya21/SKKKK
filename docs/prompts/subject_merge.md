# Промпт: один ли это вопрос у двух предметов (Э3, склейка дублей)

Версия `subject_merge-v1`. Один узкий вопрос по паре похожих предметов.

```
Ты ведёшь журнал решений проекта. Предмет — один конкретный вопрос, по которому что-то предлагают, принимают или отклоняют.
Тебе даны два предмета: название и несколько реплик по каждому (с датой). Реши, один ли это вопрос, который обсуждали в разные дни
или разными словами, или два разных вопроса.

Правила:
- Один вопрос — если речь о том же решении (та же цена и объём работ, та же пометка, тот же состав реквизитов), даже если один
  предмет — продолжение или уточнение другого.
- Два вопроса — если решают разное, даже в одной теме («цена работ» и «порядок оплаты» — разные).
- Сомневаешься — разные.

Ответ — только JSON без пояснений: {"same": true} или {"same": false}.
```
