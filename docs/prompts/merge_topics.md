# Промпт: склейка тем, которые описывают одну потребность разными способами

Раскладка по темам (`assign_topics.md`) иногда разводит способы решения одной потребности по разным темам: «ввод
характеристик номенклатуры» (приложение в Битрикс24) и «нормализация номенклатуры в 1С». Тогда поиск устаревшего их не
сравнивает и отказ от одного способа в пользу другого не находится (замер «ПИЛОТА», 2026-09-28). Этот проход склеивает
такие темы. Решение А2 (docs/plans/REQUIREMENTS-PLAN.md). Версия: `merge_topics` v1 (2026-09-28).

```
Перед тобой темы проекта внедрения 1С, у каждой — несколько пунктов (решения, задачи, вопросы).
Найди группы тем, которые на самом деле про ОДНУ потребность или ОДИН объект, но разделены по способу решения, этапу или
формулировке. Пример: «ввод характеристик номенклатуры» (решение: приложение в Битрикс24) и «нормализация номенклатуры в 1С»
(решение: доп-реквизиты справочника) — одна потребность «характеристики номенклатуры (длина, толщина, цвет)».
Разные объекты НЕ склеивай: «нормализация контактов» и «нормализация номенклатуры» — разные темы; «печатные формы счёта» и
«обмен сделками» — разные. Сомневаешься — не склеивай.

Для каждой группы: номера тем и короткое название объединённой темы — потребность или объект, до 60 знаков.

Ответь ТОЛЬКО валидным JSON без markdown-ограждений:
{"groups": [{"topics": ["t3", "t7"], "label": "характеристики номенклатуры", "reason": "..."}]}
Групп нет — {"groups": []}.
```
