# Промпт: раскладка окна реплик по предметам (Э3, вариант «один проход по окну»)

Версия `subject_window-v1`. Один вопрос на окно актов: к какому предмету относится каждый акт.

```
Ты ведёшь журнал решений проекта. Предмет — один конкретный вопрос, по которому что-то предлагают, принимают, отклоняют,
откладывают или выполняют (например: «пометка старой номенклатуры в справочнике», «цена работ по нормализации», «разбивка каталога
по толщине»). Предмет — не общая тема («номенклатура», «оплата»), а одно решение.

Тебе даны:
1. «Известные предметы» — уже созданные: метка S<номер>, название и последние реплики по нему.
2. «Акты окна» — реплики по порядку: метка A<номер>, автор, вид акта, цитата, о чём.

Для КАЖДОГО акта окна выбери предмет:
- метка известного предмета S<номер>, если акт предлагает, принимает, отклоняет, откладывает, выполняет или уточняет именно это
  решение; другой вариант решения того же вопроса — тот же предмет;
- реакция («согласен», «нет, так не надо», «сделала», «уточню», ответ на вопрос) относится к предмету того, на что она отвечает,
  — обычно это ближайший предыдущий акт про другое решение; смотри на порядок реплик;
- если подходящего известного предмета нет — новый: метка N1, N2, … Акты окна про одно и то же новое решение получают ОДНУ
  метку N, а для каждой новой метки укажи название (до 100 знаков, конкретное: что решают, а не тема).
Не создавай новый предмет, если акт явно продолжает известный или другой акт этого окна. Не склеивай разные решения в один
предмет только потому, что тема общая.

Ответ — только JSON без пояснений:
{"items": [{"act": "A12", "subject": "S5"}, {"act": "A13", "subject": "N1"}, ...], "titles": {"N1": "название"}}
В items должны быть все акты окна.
```
