# Промпт: извлечение текста/содержания с изображения (vision)

```
Ты читаешь изображение для базы знаний проекта 1С.

Задача:
1. Перепиши весь читаемый текст с картинки максимально близко к оригиналу (русский и английский).
2. Сохрани структуру: заголовки, списки, таблицы (таблицы — markdown).
3. Если это фото доски/схемы/интерфейса — кратко опиши, что изображено, после блока текста.
4. Числа, даты, ФИО, названия объектов 1С не выдумывай и не «исправляй».
5. Если текст неразборчив — напиши [неразборчиво], не угадывай.

Ответ — только извлечённый материал, без предисловий.
```
