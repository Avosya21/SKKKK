# Промпт: паспорт документа (документы в памяти решений)

Версия `document_passport-v1`. Один вопрос по началу и концу документа: что это за документ, кто его писал, утверждён ли он и от какой даты. План — `docs/plans/DOCUMENT-MEMORY-PLAN.md`. Каждый ответ подтверждается дословной цитатой; код проверяет цитату по тексту документа, ответ без подтверждённой цитаты считается «не известно».

```
Тебе дано начало и конец документа проекта внедрения (между ними текст пропущен). Ответь, что это за документ.
Отвечай только по тому, что написано в тексте. Если в тексте этого нет — пиши "unknown" и пустую цитату. Не угадывай по названию
файла и по смыслу: нужна строка из документа.

Поля:
- kind — вид документа: contract (договор, спецификация, допсоглашение), tz (техническое задание, требования), protocol (протокол
  встречи, решения совещания), plan (план работ, график, диаграмма Ганта, дорожная карта), status_report (отчёт о ходе работ, дашборд
  задач со статусами), spec (описание процессов, регламент, инструкция, архитектура), presentation (презентация), correspondence
  (письмо, служебная записка), other (другое). kind_quote — строка, по которой это видно (заголовок, «Техническое задание», «Протокол»).
- author_side — чья сторона составила документ: customer (заказчик — компания, для которой внедряют) или executor (исполнитель —
  интегратор, подрядчик); unknown — если в тексте не сказано. author_quote — строка, где это видно («Исполнитель: …»,
  «Разработал: …», «Подготовлено компанией …»).
- approved — есть ли в документе признак, что он утверждён или подписан: yes (гриф «Утверждаю», «Согласовано», подписи сторон с
  датой, «утверждено протоколом №…»), no (явно «черновик», «проект документа», «на согласование»), unknown (ничего такого нет).
  approved_by — кто утвердил: customer, executor, both (обе стороны) или unknown. approved_quote — строка с грифом или подписью.
- date — дата документа в виде ГГГГ-ММ-ДД (дата утверждения, подписи, версии или составления), если она есть в тексте; иначе "".
  date_quote — строка с этой датой как она написана в документе.

Ответ — только JSON без пояснений:
{"kind": "tz", "kind_quote": "...", "author_side": "executor", "author_quote": "...", "approved": "unknown", "approved_by": "unknown",
 "approved_quote": "", "date": "", "date_quote": ""}
```
