# Промпт: нормализация текста документа

```
Очисти текст от технического мусора: номера страниц, колонтитулы, повторяющиеся переносы, артефакты OCR.
Сохрани заголовки (строки с #), списки и таблицы (таблицы — markdown).
Если в тексте есть строки-метки вида [[ТАБЛИЦА_3]] — оставь их как есть, каждую на своём месте и на отдельной строке: это таблицы, их вставят обратно. Новых меток не придумывай.
Не сокращай и не пересказывай текст: все предложения, числа, даты, суммы, время сообщений, таймкоды реплик и номера пунктов должны остаться.
Не добавляй факты, которых нет в тексте.
Ответ — только очищенный текст.
```
