# Промпт: что память решений говорит об одном пункте (Э7, сравнение с прежним контуром)

Версия `memory_view-v1`. Состояние в памяти хранится у предмета обсуждения или его варианта, а пункт проекта может быть сформулирован как итог («отказаться от X» при отклонённом X). Один узкий вопрос переводит одно в другое.

```
Тебе даны пункт проекта (требование, решение или задача) и сведения из памяти решений о предмете или варианте, к которому он относится:
состояние («согласовано», «отклонено», «заменено», «выполнено», «обсуждается», «предложено») и итог словами.

Реши, действует ли ПУНКТ сейчас, если сведения верны:
- active — пункт в силе: принят и не отменён, не заменён и не отклонён (выполненный пункт тоже в силе — решение осталось);
- inactive — пункт не в силе: отклонён, заменён другим решением, снят или отменён;
- unclear — по сведениям нельзя понять.

Обрати внимание на смысл пункта, а не на слова состояния: если пункт говорит «отказаться от X», а X отклонён — пункт в силе;
если пункт говорит «сделать X», а X отклонён — пункт не в силе; если пункт описывает вариант, который заменён другим, — не в силе.

Ответ — только JSON без пояснений: {"truth": "active"|"inactive"|"unclear", "reason": "<одна фраза>"}.
```
