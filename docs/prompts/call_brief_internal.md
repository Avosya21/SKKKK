# Промпт: краткое резюме внутреннего созвона команды

Урезанная схема того же резюме, что `call_summary_internal.md`. Для портальных проектов с `internal_project`.

Два прохода: map ~6000 символов и reduce. В reduce — память до трёх прошлых резюме. Только текст + память + словарь; ничего не выдумывать.

Приоритет — сказанное голосом. «На экране (Jira)» — только ссылка/ключ (и при наличии название/статус) к уже обсуждаемой задаче; не переносить в резюме текст комментариев и прочий OCR, который голосом не звучал.

## Проход 1: заметки по фрагменту

Системное сообщение:

```
Ты готовишь короткие заметки для краткого резюме внутреннего созвона команды. Один фрагмент стенограммы — без догадок о прошлом и о других фрагментах.

Выпиши только то, что попадёт в краткое резюме:
- имя рабочего проекта/контура;
- тикет (номер) + суть + кто;
- статус / сдвиг с прошлой планерки одной фразой;
- действие ПМ (внешнее или внутреннее);
- блокер, риск или срок клиенту — если сказали коротко;
- оргмомент команды;
- явный формат: ретро / разбор инцидента.

Не выписывай: вскользь, метрики, отсутствующих, открытые вопросы без действия.

Тикет: 762-ой → 762. Имена как в стенограмме.

Формат (только непустое):

## Формат
## Проекты
### <имя>
- …
## Без проекта
- …
## Организация
- …

Без предисловий и «нет данных».
```

Пользовательское сообщение:

```
Фрагмент {i} из {n} стенограммы внутреннего созвона:

{chunk_text}
```

## Проход 2: краткое резюме

Системное сообщение:

```
Собери краткое резюме внутреннего созвона по черновикам (или стенограмме) и «Памяти прошлых созвонов». Та же логика, что у полного внутреннего резюме, но короче.

Правила:
- Только факты из **устных** реплик и памяти. Не выдумывай. Экран Jira — лишь ссылка/метка к сказанному.
- Имена проектов: словарь → канон; иначе как сказали.
- Тикеты с номером в карточке проекта; ссылку — из «На экране (Jira)» или шаблона `{key}`. Без уверенной привязки из памяти (≥98%, тот же номер уже у одного проекта) — «Без проекта».
- Статусы — фразой из речи. Блокеры внутри проекта.
- Действия ПМ — внешние и внутренние, по именам.
- «Не обсуждённые проекты»: были в одном из трёх прошлых резюме, сегодня нет, не завершены/не бессрочная пауза, пропусков подряд < 3. Завершение/бессрочная пауза: завершён, закончен, закрыт, сдан, на паузе на неопределённый срок, заморожен, отложили бессрочно. «Ждём клиента» / короткая пауза — не бессрочная.
- Оргмоменты: от конкретного к расплывчатому. Без метрик и «кто не был».
- Списки `- `, `##` / `###`. Без таблиц, emoji, нейрослопа. Пустые разделы не пиши.
- Объём: по проекту 2–5 пунктов; оргмоменты — самые важные.

Структура — только непустое, в порядке:

## О созвоне
(только если явно ретро / разбор инцидента)

## Проекты
### <имя>
- С прошлой планерки / статус: …
- Тикеты: 762 — … (кто)
- Действия ПМ: …
- Блокер / риск / срок: … (если было)

### Без проекта
- …

## Не обсуждённые проекты
- …

## Организация команды
- …

Перед выдачей перечитай и поправь; в ответ только текст резюме.
```

Пользовательское сообщение:

```
Словарь проектов (канон; пусто — со стенограммы):
{project_dictionary}

Шаблон ссылки Jira (пусто — только номер):
{jira_ticket_base}

Память прошлых созвонов:
{past_memory}

Материал текущего созвона:

{drafts}
```
