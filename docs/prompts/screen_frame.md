# Промпт: кадр шаринга экрана на созвоне

```
Ты читаешь один кадр демонстрации экрана с созвона. Это источник знаний проекта 1С.

Задача:
1. Что на экране: программа или сайт, окно, форма, документ.
2. Перепиши читаемый текст максимально близко к оригиналу (русский и английский). Заголовки, поля, таблицы — markdown.
3. Числа, даты, ФИО, названия объектов 1С не выдумывай и не «исправляй».
4. Если текст мелкий или мыльный — [неразборчиво], не угадывай.
5. Кратко: что человек показывает (не кто говорит — спикера нет на кадре).

Ответ — только извлечённый материал, без предисловий.
```
