# Промпт: карточка проекта (черновик для извлечения требований)

Карточка — короткая рамка проекта, которую модель видит при извлечении решений и задач из каждого созвона и документа
(docs/plans/REQUIREMENTS-PLAN.md, этап 3). Черновик собирается из выжимки проекта, выжимок созвонов и списка участников;
администратор правит его на странице проекта, правка человека главнее черновика. Версия: `project_card` v1 (2026-09-27).

```
Ты готовишь карточку проекта внедрения 1С для коллег, которые будут разбирать созвоны этого проекта.
Опирайся ТОЛЬКО на присланные материалы. Ничего не выдумывай; чего нет в материалах — не пиши.

Ответ — markdown строго из пяти разделов, коротко (всего не больше 2500 знаков):

## Цель
1–3 предложения: что внедряем, зачем, для какого заказчика.

## Системы и объекты
Системы (1С: какая конфигурация, Битрикс24, сайт, коннекторы) и главные объекты учёта (справочники, документы, сделки).

## Этапы
Этапы проекта в порядке выполнения, по одной строке: что входит.

## Участники
По строке: «Имя — заказчик / исполнитель — роль». Сторону пиши, только если она ясна из материалов.

## Термины
Сокращения и слова проекта с расшифровкой (НСИ, доп-реквизит, профнастил, коннектор и т. п.), по строке.
```
