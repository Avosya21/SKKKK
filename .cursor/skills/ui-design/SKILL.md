# UI Design

## Priorities

1. Clear hierarchy: page title -> primary actions -> main content -> secondary tools.
2. Stable layout: avoid jumping content and hidden critical actions.
3. Readability: prefer cards, whitespace, short labels, and clear section boundaries.

## For PrimaryAnalitics

- Keep project artifacts, project summary, and AI chat visibly separated but connected.
- Put the most valuable content above the fold where possible.
- Prefer simple Bootstrap composition over custom visual tricks.
