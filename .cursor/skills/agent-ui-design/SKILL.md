# Agent UI Design

## Focus

- User question, AI answer, and sources should be easy to scan.
- Show clear intermediate states while the model is thinking.
- Prefer structured answer rendering over plain text dumps.
- Keep the chat useful as a working tool, not decorative UI.

## For PrimaryAnalitics

- The chat sits beside project knowledge, so answers should feel grounded in project artifacts.
- Sources, when present, should be visible but secondary to the answer.
- Avoid clutter that pushes the input box out of reach.
