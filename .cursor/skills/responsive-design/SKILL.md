# Responsive Design

## Rules

- Preserve upload, artifact list, summary, and chat access on smaller widths.
- Let wide two-column layouts collapse to one column before content becomes cramped.
- Avoid fixed widths for primary content blocks unless scroll behavior is intentional.
- Keep embedded viewers usable with sensible heights and overflow handling.

## For PrimaryAnalitics

- The project page should remain usable on narrower laptop windows.
- Critical actions must stay visible without horizontal scrolling.
