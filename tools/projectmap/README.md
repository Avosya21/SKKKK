# projectmap

Карта любого проекта: граф файлов, функций, вызовов, интерфейсов, данных, настроек, тестов и истории правок, метрики
(группы Louvain, fan-in/out, частота правок) и **проверка полноты** — какая доля проекта описана и связана в карте.

**Статус:** каркас (этап 0 плана `docs/plans/PROJECTMAP-PLAN.md`). Реализована только команда `version`.

## Для чего

Новый проект должен подключаться к построению карты за три команды:

```
projectmap init     # определить стек, создать конфиг и заготовку карты
projectmap index    # разобрать проект и построить граф
projectmap check    # сверить карту с проектом и показать охват по слоям
```

## Устройство

- **Ядро** — формат графа, хранилище, метрики, проверки полноты. Не знает ни одного конкретного проекта: проверяется тестом.
- **Парсер языков** (tree-sitter) — символы, импорты, вызовы для многих языков.
- **Адаптеры стека** — знание фреймворков (веб-роутеры, ORM, шаблоны, Docker, оболочки, документы, git).
- **Просмотрщик** — один самодостаточный HTML-файл без интернета.

## Запуск из репозитория

```
venv\Scripts\python.exe -m pytest tools/projectmap/tests -n 0
set PYTHONPATH=tools\projectmap && venv\Scripts\python.exe -m projectmap version
```
